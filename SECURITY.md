## Reporting a Vulnerability

I take the security and integrity of this integration seriously. If you discover a security vulnerability or potential risk, please report it via GitHub Private Vulnerability Reporting rather than creating a public issue.

### Preferred Method: GitHub Private Vulnerability Reporting
Please submit a private vulnerability advisory directly via GitHub:
- **Submit Report:** [New Security Advisory](https://github.com/christopherturner/mattermost-authentik/security/advisories/new)
